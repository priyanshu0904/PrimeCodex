# Introduction
## About Java

- Wide usage - Web apps, Backend, Mobile apps(Android), Enterprise software, Desktop Apps, Cloud System, Games, IoT etc
- Object Oriented and High-level programming language

## Programming Language
- Computer Understands - 0/1 or on/off or machine code -> Dumb machine
-  Instructions / code -> Tell computer what to do -> HLL
- Compiler -> HLL(java, python etc) to LLL(machine code)
- Step-by-step procedure to solve problem or performing a task -> Algorithms
- Rule of writing code -> Syntax (Exact syntax is important)
> HLL -> High Level Language and LLL -> Low Level Language

## History of Java
- Created by James Gosling at Sun Microsystems in early 1990s.
- First named as 'Oak', later 'Java' during first release in 1995. Oak -> tree and java -> island (famous for Coffee beans)
- Write Once, Run Anywhere :- Principle of Java, Platform Independent
- Backward Compatibility -> New versions can run in older one -> Coffee mug logo related
- In 2008-09, occupied by **Oracle**.
- After 2016, many Java versions had released.
- C/C++ directly compiles to machine code and that can not be run on different machines.
- Java/Python uses bytecode concept. JVM converts machine specific machine code or LLL.
- **Timeline and History**: Exponentially growth
    - Rapid Growth and Diversification (Late 1990s-2010s): Expanded from web applets to server-side applications; standardized into different editions for various computing platforms
    - Many version release after 2016-17

## ByteCode
- ByteCode -> Platform Independent, not human understandable, not machine code.
- Java compiler(javac): Source code to Bytecode and JVM (individual machine): Bytecode to machine code and starts execution (interpreter)
- Bytecode must not be changed.
- Bytecode can execute in any machine using its JVM
- It provides security because code runs on Virtual Machine. Java changed the internet, portability with write once, run anywhere
