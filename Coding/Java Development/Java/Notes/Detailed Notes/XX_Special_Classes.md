# Special Classes
## Math Class
- Methods are static, used by class name
- Constants are PI, E, Base of log which is e
- abs() -> absolute value
- ceil() -> rounds up
- floor() -> rounds down
- round() -> rounds to nearest integer
- max(), min() -> Maximum or Minimum of two numbers
- pow() -> calculates power
- sqrt() -> square root
- random() -> random number generation
- exp(), log() -> Exponential and logarithmic functions
- sin(), cos(), tan() -> trigonometric functions
