# Methods
- Reusable code, perform specific task, Code organization
- DRY Principle "Don't Repeat Yourself"
- camelCase naming
- Function or method declaration, definition and calling.
- Methods calls -> Code jump around

## Method Syntax
```java
access_specifier return_type method_name(data_types parameters){
	//Block of code
	//return statement
}
```

## Return Statement
- Returns a value from function
- Ends function immediately
- Jumping statement.
- return value;

## Arguments vs Parameters
- Both are input, function takes
- Parameter : Function definition
- Arguments : Actual value, function call
- Function called -> Copy sends to definition
- camelCase naming.
- Can be multiple parameter, can be default
- **There are four PnC** : 
	1. no parameter no return type(void)
	2. no parameter with return type
	3. with parameter no return type 
	4. with parameter with return type
